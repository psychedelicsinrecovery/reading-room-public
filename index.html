Ask for access

Three steps. Your GitHub name is shared only with the stewards.

  1. Have a GitHub account with two-factor on. Free is fine. Use a name you're comfortable with; anonymity comes first.
  2. Ask. Type /github in PIR®'s Discord, or use the web helpdesk, and say "reading room, please".
  3. Accept the invitation. On an officer's yes you're added to the readers. Accept the email (or the bell on GitHub), then open the private room.

Reading is all the room gives: nobody can change anything in it by reading. If a link doesn't open, send the address and the error, never a password.
